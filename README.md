# Wilkerson Collective University — Cinematic Vertical Slice

An original, dependency-free, private AI-powered university experience.

## Run it

Double-click `START-WILKERSON-UNIVERSITY.cmd`. The launcher starts both:

- University: `http://127.0.0.1:3000/`
- Founder Tool Suite and Voice Engine: `http://127.0.0.1:8788/`

The two services work together so university read-aloud still functions when the browser does not provide built-in speech.

## Honest boundaries

This is a private, non-accredited educational and study system. It does not award accredited degrees, licenses, or professional certification. The campus is a cinematic photographic vertical slice, not yet a freely walkable Three.js world. Full-body identity-faithful avatar generation requires user-approved full-body references. Live generative tutoring, authentication, database storage, secure code execution, and real-time lip-synced avatars require later phases and/or configured services.

No API keys belong in frontend files. A production AI connector must be server-side.

## Brand direction

The crest is wholly original: a divided indigo shield with a luxury WC monogram, globe for knowledge of the world, open book for scholarship, torch and constellation for wisdom and innovation, oak branches, silver trim, and a gold Established 1971 ribbon. It uses formal academic heraldry without copying any real institution's seal.
