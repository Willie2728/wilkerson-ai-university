**Body:** Run a browser exercise. Review the current curriculum. Inspect the lesson records that actually exist. The product should earn enrollment through an inspectable learning experience—not through accreditation, career, recognition, or outcome claims it cannot verify.

**CTA:** Try the Coding Lab. Browse the current programs. Enroll only if the learning surface fits.
