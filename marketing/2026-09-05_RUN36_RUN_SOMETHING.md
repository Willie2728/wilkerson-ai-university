## Customer Truth

**AI familiarity is not the same thing as applied practice.**

Current education/workforce research points to a gap between widespread AI use and hands-on instruction or demonstrated applied competency. Use that only as market context, not as proof of learner outcomes from Wilkerson AI University.

## Product-grounded campaign

**Hook:** Don't just watch AI. Run something.

Wilkerson AI University already contains a browser-based JavaScript Coding Lab with starter templates, an editable code surface, a Run action, and console output.

The grounded learning path is:

`course / lesson → open Coding Lab → edit code → run → inspect output → reset / revise → try again`

**CTA:** Try the Coding Lab.

Suggested buyer/learner copy:

> Watching an AI lesson can explain a concept. Running something makes you confront what the code actually does. Wilkerson AI University's browser Coding Lab lets you edit JavaScript, run it, inspect the output, reset it, and try again inside the learning environment. Start with a course, then test the idea yourself.
