# Run 28 — Learn It. Run It.

Date: 2026-09-05
Product: Wilkerson's AI University
Status: Prompt Ready / text only / not published

## Customer truth

The connected product is strongest when it behaves like a study environment rather than a passive course catalog. It currently exposes a private digital campus, course/lesson views with progress tracking, and a working browser-isolated JavaScript Coding Lab with editable starter templates and console output.

## Creative strategy

**Hook:** The next click after an AI lesson should be **Run**.

**Body:**
Reading about AI is useful. Changing the code, running it, seeing the output, and trying again is where the concept becomes yours.

Wilkerson's AI University combines a private study catalog with lesson progress and a Coding Lab sandbox so an AI learner can move from concept to practice without opening another tool.

`course → lesson → objective → edit code → run → inspect output → continue`

**CTA:** Enter the campus, open an AI course, then take one concept into the Coding Lab.

## Product-truth / claims review

The connected Home page already labels Wilkerson's AI University as a **non-accredited personal educational and study-guide system**. Run 28 preserved that boundary.

A fresh entity read found 0 Enrollment records while Course data contained large `students_count` values and rating fields. Because those values are not supported as verified enrollment/review outcomes by the connected data, Run 28 removed public rating and student-count displays from CourseCard and CourseDetail. Course duration/level and the working Coding Lab remain visible.

No accreditation, licensing eligibility, job outcome, student-popularity, course-rating or completion-result claim is made in this campaign.
