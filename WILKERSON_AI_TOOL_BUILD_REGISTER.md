# Wilkerson Collective AI Tool Build Register

Updated: August 5, 2026

This register defines original Wilkerson-branded products inspired by publicly described capability categories. It does **not** authorize copying proprietary source code, bypassing subscriptions, evading authentication, cloning protected brands, or violating service terms. Open-source components may be used only under their actual licenses.

## Current working foundations

| Wilkerson product | Capability category | Current verified state | Production expansion |
|---|---|---|---|
| **Wilkerson Context Engine** | Public-page extraction and structured context | **Working:** bounded public HTML/text retrieval, DNS and private-network blocking, basic robots enforcement, title/description/headings/text/link extraction, rate limits, and JSON export | Rendered JavaScript pages, whole-site crawl jobs, document parsers, screenshots, queues, and citations |
| **Wilkerson Browser Pilot** | Web QA and controlled browser workflows | **Working:** HTTP and markup review for status, title, description, H1, language, viewport, and obvious missing alt attributes | Permission-gated Playwright workflows, traces, screenshots, and cross-device test matrices |
| **Wilkerson Voice Engine** | Speech and captions | **Working:** server-side Windows System.Speech generation, browser playback, and WAV download | Piper or Riva adapter, speech recognition, caption timing, approved custom voices, and non-Windows deployment |
| **Wilkerson Persona Live** | Consented digital humans | **Working foundation:** approved Willie portrait, generated speech, audio playback, and responsive speaking motion | Phoneme-level lip sync, facial animation, WebRTC conversation, persona grounding, consent records, and provenance marking |
| **Wilkerson MotionLab** | Motion and video production | **Working foundation:** local image/video loading, motion preview, media metadata, and downloadable storyboard | Pose extraction, image-to-video providers or open models, Blender retargeting, render queues, and GLB/BVH/FBX/video export |
| **Wilkerson Forge** | Prompt-to-application building | **Working foundation:** concept-to-responsive standalone HTML, live preview, interactive control, and file download | Multi-page projects, component generation, data schemas, server services, authentication, safe code execution, Git export, and deployment adapters |
| **Wilkerson Broadcast Studio** | Content remixing and distribution | **Working foundation:** brief-to-four-channel draft package with JSON export | Original media assembly, captions, calendar, OAuth account connections, approval queue, scheduling, and supported platform publishing APIs |
| **Wilkerson Skill Exchange** | Audited AI skill marketplace | **Working foundation:** portable skill manifest builder with permission, input, output, review, and provenance fields | Signed packages, versions, compatibility checks, installation sandbox, reviews, and a private catalog |
| **Wilkerson Agent Core** | Local agent orchestration | **Working foundation:** auditable dry-run workflow planner with explicit external-action gates | Tool registry, isolated execution, schedules, memory controls, secrets vault, observability, and per-tool approvals |
| **Wilkerson Avatar Lab** | Identity-faithful avatar configuration | **Working university foundation:** approved Willie headshot, residence experience, saved wardrobe, and 6 ft 3 in / 230 lb body profile | User-approved full-body references, body model, landmarks, expression analysis, lip sync, talking-head rendering, and provenance metadata |

## Public comparison and open-source research map

These are capability references, not source-code cloning instructions.

| Product | Public comparison category | Lawful implementation direction |
|---|---|---|
| Forge | Base44 / Lovable-style builders | Original templates and generators, model-agnostic adapters, schema-first services, and sandboxed preview |
| Context Engine | Firecrawl | Expand the original extractor or evaluate Firecrawl's public AGPL-3.0 repository under its license |
| MotionLab | DeepMotion / Kling-style motion tools | MediaPipe or OpenPose-compatible pose analysis, Blender, ComfyUI adapters, and licensed model/provider connectors |
| Persona Live | Tavus / Daily-style conversational video | Approved identity assets, local speech, Pipecat or LiveKit-compatible WebRTC, consent, and provenance |
| Broadcast Studio | Blotato / Crayo-style content workflows | Original project library, FFmpeg, captions, calendars, supported APIs, and approval queues |
| Browser Pilot | Playwright / Selenium | Playwright-first automation with allowlists, consent gates, secret redaction, and audit logs |
| Skill Exchange | LarryBrain-style skill discovery | Original signed manifests, permissions, local package registry, trust states, and audited installation |
| Agent Core | OpenClaw-style local orchestration | Evaluate lawful upstream use or write narrow original adapters with isolation and approval boundaries |
| Voice Engine | NVIDIA Riva-style speech | Windows speech now; Piper-compatible local adapter or licensed Riva adapter later |
| Avatar Lab | OpenFace / LibreFace-style analysis | Consent-bound open analysis tools plus licensed local/provider render adapters |

## Verification rule

Every feature must be labeled **Working**, **Working foundation**, **Demonstration**, **Planned**, **Requires provider configuration**, or **Blocked**. A rendered control is never treated as evidence that a backend capability exists.
